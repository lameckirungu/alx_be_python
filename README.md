# ALX BE Python Solutions

A comprehensive collection of Python programming exercises and solutions developed as part of the ALX Backend Engineering program. This repository showcases progressive learning in Python, covering fundamental concepts through advanced programming paradigms.

##  Overview

This repository documents the journey through Python programming fundamentals, demonstrating proficiency in core concepts, control structures, functions, data structures, object-oriented programming, and various programming paradigms. Each directory contains practical implementations that solve real-world programming challenges.

## Repository Structure

### `python_introduction/`
Introduction to Python basics, including fundamental operations and simple calculations:
- Basic arithmetic operations
- Time conversion utilities
- Area calculations
- Financial calculators (simple interest, savings projections)
- Age calculators

### `control-flow/`
Implementation of Python control structures and flow mechanisms:
- **Conditional Statements**: Weather advice system, daily task reminders
- **Loops**: Pattern drawing, multiplication tables
- **Match-Case**: Calculator with pattern matching

### `fns_and_dsa/`
Functions and Data Structure Algorithms, focusing on modular code and practical utilities:
- **Arithmetic Operations Module**: Reusable arithmetic functions
- **Temperature Conversion Tool**: Fahrenheit ↔ Celsius converter with global constants
- **Shopping List Manager**: Interactive CLI application for list management
- **DateTime Utilities**: Current datetime display and future date calculations

### `oop/`
Object-Oriented Programming implementations demonstrating advanced OOP concepts:
- **Magic Methods**: Custom `Book` class with `__init__`, `__del__`, `__str__`, and `__repr__`
- **Inheritance & Composition**: Library system with `Book`, `EBook`, and `PrintBook` classes
- **Polymorphism**: Shape hierarchy with `Rectangle` and `Circle` implementations
- **Class & Static Methods**: `Calculator` class demonstrating decorators

### `programming_paradigm/`
Advanced programming concepts including encapsulation, error handling, and testing:
- **Encapsulation**: `BankAccount` class with deposit/withdraw functionality
- **Exception Handling**: Robust division calculator with `try-except` blocks
- **Library Management System**: Complex class interactions with `Book` and `Library` classes
- **Unit Testing**: Comprehensive test suite for calculator functionality

##  Key Learning Outcomes

- **Core Python Syntax**: Variables, data types, operators, and basic I/O
- **Control Structures**: Conditionals, loops, and pattern matching
- **Functions**: Definition, parameters, return values, and scope
- **Data Structures**: Lists, dictionaries, and data manipulation
- **OOP Principles**: Classes, inheritance, polymorphism, encapsulation, and abstraction
- **Magic Methods**: Understanding and implementing Python's special methods
- **Error Handling**: Try-except blocks and graceful error management
- **Testing**: Writing unit tests with Python's `unittest` framework
- **Best Practices**: Code organization, documentation, and Pythonic patterns

##  Technical Highlights

- **Type Hints**: Modern Python type annotations for better code clarity
- **Error Handling**: Comprehensive exception management
- **Documentation**: Well-documented code with docstrings
- **Design Patterns**: Implementation of common OOP design patterns
- **Testing**: Unit tests demonstrating TDD principles
- **CLI Applications**: Interactive command-line tools

##  Usage

Each directory contains standalone Python scripts that can be executed independently. Most scripts are interactive and will prompt for user input. For example:

```bash
# Run the temperature conversion tool
python fns_and_dsa/temp_conversion_tool.py

# Try the shopping list manager
python fns_and_dsa/shopping_list_manager.py

# Test the calculator
python programming_paradigm/test_simple_calculator.py
```
